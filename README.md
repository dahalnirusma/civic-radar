# Civic Radar

**Keeping busy people up to date on legislative bills.**

Civic Radar tells you how state legislation affects you. Enter a few topics you care about (for example "housing" or "school funding") and your zip code, and it finds recent bills on those topics, explains what each bill does in plain language, and shows why it matched your topic, with a quote from the bill itself.

**Live site:** https://civic-radar-liart.vercel.app/

> Coverage today: **Virginia** bills with activity in the last 90 days. See [Limitations](#limitations).

## What it does
 
1. Add up to five topics and enter a zip code. The zip code is resolved to a county.
2. Civic Radar searches recent bills in your state and keeps only the ones that are genuinely about your topics.
3. Each result card shows the bill, an AI-written summary, and one tag per matching topic.
4. Open a bill to see a longer explanation for each topic, with a quote from the bill text that supports it.
5. Thumbs up / down on a card tells us whether the match was relevant.

## Deployment
 
Deployed on Vercel.

# Limitations
 
- **One state.** Only Virginia is supported. Every state publishes bill text differently, and some restrict automated access. Each new state needs its own text source and parser, so I scoped this project to the one state that works end to end.
- **Zip codes can span counties.** Where a zip code covers more than one county, the user picks one. Today the county is only used to select the state; county-level bills aren't covered.
- **Recent activity only.** Bills with activity in the last 90 days.
- **AI-written text can be wrong.** Summaries and explanations are generated by a language model. The quote check keeps explanations tied to the bill text, but summaries are not independently verified. Please reference back to the bill text for confirmation.
- **No rate limiting.** Spending on the paid APIs is capped by prepaid credit rather than by per-visitor limits. Public traffic could exhaust the credit, which would pause new searches until it is topped up. Cached results keep working.
- **Feedback is anonymous and unauthenticated**, so votes can be repeated or manipulated. It is a relevance signal for tuning, not a ranking input.
- **Not legal or political advice.**
